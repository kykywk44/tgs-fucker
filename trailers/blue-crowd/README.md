# Синий пак · толпа за ноутбуками

12 секунд, 1920×1080, 60 fps, H.264 MP4, без звука. Исходные TGS и состав паков не меняются.

Полный пайплайн, решения и ошибки: [docs/trailers.md](../../docs/trailers.md).
Одна команда: `powershell -ExecutionPolicy Bypass -File trailers/blue-crowd/build.ps1`.
Только сжатие уже готового мастера: добавить `-TelegramOnly`.

```powershell
node trailers/blue-crowd/assets.mjs
python trailers/blue-crowd/render.py
Copy-Item trailers/blue-crowd/preview.html exports/blue-crowd/preview.html
python trailers/blue-crowd/telegram.py
```

Нужны уже установленные Node/npm-зависимости проекта, Python с Pillow и FFmpeg.
Pillow используется для композиции кадров, FFmpeg — для кодирования видео; графика рисуется
тем же tlottie, что и в редакторе. Никакие изображения персонажей не генерируются заново.

Результаты: `exports/blue-crowd/blue-crowd-trailer-v3.mp4`, `poster.png`, `storyboard.jpg`,
`motion.json`, `verification.json`, `blue-crowd-telegram.mp4` (около 2.1 MB).
Первая версия MP4 сохранена отдельно.
При работающем редакторе зацикленный просмотр доступен по адресу
`http://localhost:5173/exports/blue-crowd/preview.html`.

## Сцена

- Точные `ready/technologist-bust.tgs` (ноутбук с n) и `ready/middle-finger.tgs`.
- Шесть непрозрачных рядов. Между пятью задними рядами и первым — один экранный
  белый градиент сверху вниз до прозрачности. У персонажей нет прозрачности по глубине.
- В каждом ряду сначала рисуются все тела, затем все ноутбуки. Плечи соседей
  скрываются за крышками; между рядами сохраняется правильный порядок глубины.
- Набор текста: первые движения исходного technologist, без закрытия крышки и без
  предназначенных для её закрытия кистей поверх дисплея. Фазы и скорости независимы.
- Пролёт вправо с параллаксом. Косинусные разгон и торможение, остановка 3.8–6.5 с.
- Герой останавливает печать 3–3.8 с, после паузы опускает крышку 4.05–4.85 с
  правой рукой (слева для зрителя). Кисть привязана к углу крышки и находится под ней.
- Сначала выглядывает, затем наклоняет голову и поднимает отзеркаленную левую руку
  справа для зрителя (5.05–5.7 с). Кисть увеличена до 48%; её низ скрывает ноутбук.
  Контуры обеих кистей имеют ширину 7.44 px в координатах сцены 512×512.
  Покойная поза без исходного тычка/тряски, лёгкое покачивание запястья ±1.2°,
  после начала движения камеры — несколько махов до ±8° с плавным входом и затуханием.
- Рот с зубами и покачивание головы взяты из готового Face with Hand Over Mouth:
  сохранены исходные кривые, безопасный участок кадров 20–115. Рот увеличен до
  60% исходника; минимальная высота 65%, без исчезающей тонкой линии и без фейда.
- Кисть на крышке выходит из-за панели по дуге и доходит до положения захвата.
- Камера трогается в 6.5 с, пока жест удерживается. Рука опускается 7.8–8.4 с,
  голова возвращается, ноутбук открывается 8.55–9.65 с. Герой остаётся в задумчивой
  позе без печати и уезжает за левый край кадра.

Все параметры расположены в `scene.json`. Мир повторяется через восемь колонок; движения
толпы имеют целое количество циклов за ролик. Кадр в 12 с пиксельно равен кадру в 0 с;
скорость камеры на стыке одинакова. `render.py --preview` собирает раскадровку и проверяет
этот стык без кодирования MP4. Также проверяются точное совпадение позы на входе
героя, неподвижность после остановки печати, непрозрачность рта и предел покачивания руки.
