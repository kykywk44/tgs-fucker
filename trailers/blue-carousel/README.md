# Широкая лента эмодзи

`node trailers/blue-carousel/build.mjs` → `exports/blue-carousel/`.
1920×360 (16:3), 60 fps; облегчённый MP4 1280×240, 30 fps. Белый фон,
один эмодзи в центре. Никаких подписей или добавленной графики.

Начало: N-bubble растёт из маленького размера, повёрнутого по часовой стрелке,
разворачивается против часовой в ноль с небольшим масштабным перелётом.
После бабла: facepalm (кадры 124–171, удар ладонью по лбу), удостоверение,
празднующее лицо. Далее случайная воспроизводимая подборка из готового синего
пака с ускорением до 0.05 секунды. На замедлении: гроб → кричащее лицо →
закрывающийся ноутбук (кадры 64–99) → семья → флаг.
Skibidi исключён явно. В конце N-флаг играет исходные 180 кадров ровно один раз,
после чего последняя поза линейно уменьшается в ноль за 0.18 секунды без
вращения и растворения. Начало и конец пиксельно белые, стык непрерывен.
Общая длительность — 11.2 секунды.
Текущие MP4 имеют суффикс `v3`; предыдущие `v1` и `v2` сохранены отдельно.

`timeline.json` хранит порядок, интервалы, фазы, исходные кадры и SHA-256
использованных TGS. Каждый кадр эмодзи рендерится родным tlottie. Оба MP4
декодируются полностью после кодирования, без звука, H.264/yuv420p/faststart.

Одобренные ролики для поста собраны отдельно в `exports/post-videos/`.
