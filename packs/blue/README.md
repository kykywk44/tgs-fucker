# Синий пак

Стикеры в стиле синих человечков-силуэтов (эмодзи Telegram 👤 👥 🫂 🗣). Пак начат 2026-10-21.

## base/ — исходники, не правятся

| Файл | Эмодзи | Корневой `nm` | Размер |
|---|---|---|---|
| `bust.tgs` | 👤 | Bust in Silhouette | 2.5 KB |
| `busts.tgs` | 👥 | Busts-in-silhouette | 3.8 KB |
| `hugging.tgs` | 🫂 | People-hugging (= `samples/HugsSticker.tgs`, есть профиль частей) | 7.9 KB |
| `speaking-head.tgs` | 🗣 | Speaking-head | 7.6 KB |

Все: 512×512, 60 fps, 3 с (`ip` 60 → `op` 240), `bash scripts/check.sh packs/blue/base/*.tgs` проходит
(у 👥 и 🫂 — заметка про матты, это файлы самого Telegram). tlottie рисует кадр 512 px за 0.6–1.8 мс.
У 👤 двойная вспышка-«двойник» около 2-й секунды задумана автором.

Лежат не в `samples/`: тесты требуют профиль для каждого образца, а у трёх из четырёх его пока нет.

## Стиль

- Контур: `#335375`
- Тело: градиент `#44688b` → `#6086a7` → `#7ba3c3`
- Блик по краю: `#a5d6ea`
- Рот, зубы: `#ffffff`

## Перекраски готовых эмодзи

Каждый эмодзи — папка `packs/blue/<имя>/`: `source.tgs` (оригинал Telegram, не правится) + `recipe.json`
(какой цвет во что; `library` — номер исходника в `library/emoji/`). Сборка: `node scripts/restyle.mjs blue/<имя>` → `exports/blue/<имя>.tgs`.

| Эмодзи | Папка | Соответствие цветов |
|---|---|---|
| 🖕 167 ✅ | `middle-finger/` | контур `#e17c00` → `#335375`; кожа `#fcce2c` → градиент тела; блики `#ffd75d` → `#a5d6ea`; тени `#f09201` → `#44688b` (тёмный контурный делал ладонь слишком тёмной) |

Общие цвета пака — в `style.json` (`colors` + `ramp` для прочих тёплых оттенков), так что рецепт руки — это обычно только `library`.

### 👉👌 палец в окей (`finger-ok/`, 2026-10-21)

Статичная сцена пользователя (`source.tgs`: задняя часть «ОК», рука с пальцем, колечко поверх пальца) перекрашена
(`recipe.json`, свой градиент у каждой руки — `gradients`) и оживлена `node packs/blue/finger-ok/build.mjs`:
палец ходит вдоль своей оси в колечко и обратно (4 толчка за 3 с: быстро внутрь, короткая задержка, медленнее наружу),
«ОК» подаётся вправо-влево навстречу с отставанием в 3 кадра; сцена сдвинута в кадр (`view`). Параметры — `finger-ok/motion.json`.
Тень от «ОК» на указательном пальце стоит под кольцом и видна только на пальце (маска по силуэту пальца),
а её левый конец едет с пальцем — полоса растягивается (`strip.edge`); тень пальца на ладони внутри колечка — сдвинутый силуэт самой руки (`palm_shadow`), ровная;
едет и наклоняется с пальцем (слой — дочерний у руки с пальцем) под пальцем, большой и верхний палец кольца её перекрывают (маска по ладони). Три раскрытых пальца «ОК» пружинят:
изгиб контура выше основания пальцев (`bend`: затухающая пружина от ускорения руки, ключи только в пиках).
Пальцы пружинят слегка (3°). Тройные стопки полупрозрачных теней слиты в одну копию той же плотности. 46.4 KB.
