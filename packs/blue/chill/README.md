# Синий · Chill

Пользовательский `chillstick.tgs`, перекрашенный в палитру синего пака.
Фиолетовые части, кнопки, сердечки, свечение и розовые искры становятся синими.
Палитра следует исходной яркости: тени и объём сохраняются, светлые отражения
переходят в светло-голубой. Нейтральные/бирюзовые отражения металла и белый
не перекрашиваются; слои капель сохранены целиком.

Изменяются только RGB в исходных заливках, контурах и градиентах, включая
анимированные цвета. Позиции/альфа градиентных стопов, все пути, ключи движения,
блики, прозрачности, время появления сердечек и полный луп остаются исходными.

```powershell
node packs/blue/chill/build.mjs
.venv/Scripts/python.exe .venv/Scripts/tgs_check.py --level Warning exports/blue/chill.tgs
node scripts/library.mjs
```

Результат: `exports/blue/chill.tgs`, 512×512, 60fps, 3с, около24KiB.
Сравнение: `exports/sheets/blue-chill.png`. В приложении — «Синий пак · черновики».
