# Счётчик человечков · 189

Отдельный новый WebM-эмодзи. Исходник189 сохранён побайтно в source.tgs.
Из него взяты L-light/L-dark/L-silhouette в исходной позе0; поздний рот,
правый персонаж и пальцы не используются. Персонаж не перерисован.
Все свойства заморожены на0. Копии едут влево, левый перекрывает правого.
Номера1,2,3… прикреплены к головам; Roboto Black из того же glyph.mjs,
что используется для буквы n. Белые цифры с тонким тёмно-синим контуром.

## Сборка

`node packs/blue/counting-crowd/build.mjs [проходы=92]`

100×100, прозрачность,10fps, скорость20px/с, шаг голов40px (2с на голову).
Растр тела кэшируется для40 фаз сдвига; десять цифр отрисовываются один раз.
На каждом кадре меняются только номера и фаза; нет тысяч копий вектора в памяти.
VP9 CRF42, длинный интервал ключевых кадров, без звука.

Итог92 прохода:184с,1840 кадров, на экране появляются номера до94 включительно.
261686байт (255.55KiB), лимит262144. Проба93 прохода/186с —264461байт,
уже не помещается. Это максимум среди целых проходов для выбранных настроек;
снижение качества/fps либо изменение скорости изменит предел.

Выходы:
- exports/emoji/counting-crowd.webm — черновик для загрузки, Duration2.99;
- exports/counting-crowd/counting-crowd-preview.webm — честные184с для просмотра;
- result.json, verification.json и decoded-preview.png — параметры и проверки.

`node packs/blue/counting-crowd/verify.mjs` полностью декодирует все1840 кадров,
проверяет альфу, отсутствие пустых кадров, повторение позы тела, точность
исходника и неизменность всех байтов кроме EBML Duration. После финала номера
сбрасываются к1; это конечный файл, не настоящий бесконечный счётчик.
Длительность превышает официальные3с; серверный приём и воспроизведение184с
во всех клиентах Telegram ещё не проверены. В набор не добавлено, ботом не отправлено.

`node scripts/library.mjs` обновляет вкладку «Черновики» в редакторе.
