# L · Loser · поза 145 и движение 143

По указанию пользователя взята готовая анатомия Telegram 145, кадр 70:
указательный вверх, большой в сторону, три остальных пальца согнуты.
`source.tgs` — неизменённый 145, `motion-source.tgs` — неизменённый 143.
Контуры пальцев, ладонь, складки и блики не перерисовываются; цвета заменены
общим restyle пака, как у остальных готовых рук.

Поза 145 заморожена в кадре 70. Слои, невидимые в этой фазе, исключены, чтобы
не появлялись лишние контуры мизинца. Перенесены три исходных null-слоя 143:
ULTRA, Null Rotation, Null Up Down — с исходными ключами/easing и родителями.
Кисть качается целиком и сохраняет L. По следующей просьбе пользователя добавлен
изгиб указательного: смещения его кончика взяты из морфинга `Index 4` в 143,
вместе с исходными ключами/easing. Большой пружинит с амплитудой 30% от указательного.
Изгиб плавно сходит к нулю у оснований пальцев; блики, тени и общие участки ладони
деформируются согласованно. Три согнутых пальца остаются в исходной позе.
Параметры — `recipe.fingerFlex`; перенос изгиба — `finger-flex.mjs`.
Общий масштаб 86% удерживает все 180 кадров в холсте, минимальный запас — 15 px.
