# 🤦 Facepalm · 211–213

Одобрен пользователем 2026-10-21. Три исходных варианта объединены в один синий силуэт;
основа — 213. `source.tgs` — неизменённая копия `library/emoji/213.tgs`.

```bash
node packs/blue/facepalm/build.mjs
bash scripts/check.sh exports/blue/facepalm.tgs

```

Голова — одобренный контур family с ушами и круглым подбородком, без шеи.
Его параметры читаются из `family/heads.json`, исходные пути — из `base/bust.tgs`.
Сохранены исходные ключи деформации головы и весь риг 213: рука опускается,
поднимается и снова ударяет по лицу, с исходной белой вспышкой и белым ртом.
Волосы, глаза, брови и нос исключены.

По уточнению пользователя **одежды нет**: сохранён только внешний контур плеч,
удалены воротник, шея, швы, рукав и манжета. Вместо рукава — голое предплечье,
которое следует за исходным запястьем кисти. Поперечной обводки запястья нет.
Общий градиент кисти и предплечья исключает цветной край на запястье.
Три исходные тени ладони, обрывавшиеся по запястью, исключены; блики/детали пальцев
сохранены. Обводки головы, тела и руки — 8 px, #335375; блик головы — #a5d6ea.

Предплечье и концы общего градиента запечены в векторные ключи на 180 кадров;
expressions, маски и матты не используются. Все исходные layer transforms, родители,
мимика рта и Splash сохранены. Сборка проверяет исходник, риг, рот, форму плеч,
ссылки родителей, Telegram и отсутствие пустых кадров.

После одобрения пользователь заметил две чёрточки на стыке обводок запястья.
Раздельные контуры кисти и предплечья заменены **одним непрерывным замкнутым
контуром**, без концов линий на запястье. Он запечён через два кадра, координаты
округлены до 0.01; исходные заливки кисти, пальцы, риг и тайминг сохранены.
Экспозиция объединённого контура следует исходной непрозрачности кисти.
