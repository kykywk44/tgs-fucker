# 💩 111 · синий вариант

Черновик от 2026-10-21. Пользователь: синий цвет, убрать мух, дым и глаза,
оставить рот и исходное движение из стороны в сторону.

```bash
node packs/blue/poop/build.mjs
bash scripts/check.sh exports/blue/poop.tgs
node scripts/library.mjs
```

`source.tgs` — неизменённая копия `library/emoji/111.tgs`.
`recipe.json` исключает глаза/зрачки/веки, все пять слоёв мух и слой дыма;
коричневые контуры → #335375, объёмные градиенты → #44688b…#7ba3c3,
блики → #8cb7d3. Отдельная замена #562312 нужна для тёмного края градиента:
этот оттенок выходит за диапазон тёплых тонов общего mapper.

Сборка запускает restyle, оставляет у рта исходные Group 1/2/3 с белой заливкой,
исключает внешние коричневые тени губ и удаляет 47 неиспользуемых ассетов дыма.
Геометрия тела и улыбки, родительский риг, ключи и все движения сохранены.

`exports/blue/poop.tgs`: 6.2 KB, 512×512, 60 fps, 3 с. Сравнение:
`exports/sheets/blue-poop.png`; крупные и все 180 кадров — `exports/sheets/poop/`.
Отчёт проверки исходников, движений, палитры и геометрии:
`exports/sheets/poop-heart-verification.json`.

в `packs/blue/ready/poop.tgs`. Общие скрипты и UI не менялись, коммитов нет.
