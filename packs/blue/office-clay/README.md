# Офисные гаджеты

Из пользовательского `clay.tgs`: вместо трёх глиняных табличек — стопка техники.
Снизу закрытый ноутбук556 с серой n из готового technologist-bust, посередине
клавиатура557, сверху небольшой телефон554. Ноутбук и клавиатура повёрнуты
на90° в своей плоскости: длинная сторона идёт вдоль стопки, как у телефона.
Кость заменена полной чёрной ручкой из168 без руки. Пыль/частицы удара,
глиняные поверхности, надписи и тень кости удалены.

В source.tgs лежит точный пользовательский исходник; laptop/keyboard/phone/pen.tgs
— точные доноры из библиотеки. Геометрия техники зафиксирована в нужных позах:
ноутбук25 (закрыт), клавиатура0 без летящих символов, телефон0/37 (экран/спинка),
ручка0. Сохранены исходные контуры, материалы, клавиши, иконки экрана и камеры.
Плотная анимированная тень клавиатуры вместе с её маттом исключена ради размера;
маленькие тени/скосы клавиш остаются. Жёлтый матт телефона не рисуется, сами иконки
перенесены из вложенной композиции. Серый диск и n заменяют полный логотип
Telegram на крышке ноутбука; n — тот же вектор Roboto Black, что в готовом паке.

Движение: родительские слои и все ks ключи исходных табличек/кости сохранены.
Их меняющиеся плоскости переносятся на гаджеты через вложенные поворот/масштаб/
поворот (SVD), без запекания сотен кадров каждой клавиши. Доноры один раз
выправляются гомографией, а динамика хранится в обычных трансформациях групп.
Телефон занимает34% ширины/62% длины плоскости, клавиатура100%/43%, ноутбук
108%/80% до поворота последних двух на90°. Это сохраняет разные размеры предметов.

```powershell
node packs/blue/office-clay/build.mjs
node packs/blue/office-clay/verify.mjs
.venv/Scripts/python.exe .venv/Scripts/tgs_check.py --level Warning exports/blue/office-clay.tgs

```
