# Troll face

Пользовательский `MemeEmoji_AgADdRwAAmsAAcFK.tgs.zip`, 2026-10-22. `source.tgs` — точные байты TGS из архива.

`node packs/blue/troll-face/build.mjs` собирает два черновика:

- `exports/blue/troll-face.tgs` — исходные складки лба, щёк, подбородка и уголков рта, тёмно-синие;
- `exports/blue/troll-face-smooth.tgs` — гладкий синий силуэт и улыбка.

Сохранены форма troll face, форма улыбки, исходная иерархия и движение всех 180 кадров.
Глаза, брови и нос скрыты; их слои остаются как невидимые родители для исходного рига.
Градиент #44688b → #6086a7 → #7ba3c3 нанесён на внешний силуэт без исходной вставной заливки.
Обводка #335375, 10 px; её верхняя дуга — #a5d6ea на тех же исходных анимированных вершинах.
Зубные ряды белые; широкие фиолетовые промежутки заменены тонкими синими разделителями
на основе исходных движущихся промежутков, как в grimacing-face.
Нулевой skew из исходника исключён для Telegram; изображение от этого не меняется.

`node packs/blue/troll-face/verify.mjs` проверяет риг, контур, улыбку, зубы, палитру и границы всех кадров.
Сравнение: `exports/sheets/blue-troll-face-compare.png` (оригинал / со складками / без складок).
Оба варианта доступны в библиотеке черновиков; в ready/ автоматически не добавляются.
