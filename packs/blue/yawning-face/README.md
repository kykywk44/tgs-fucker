# 089 + 090 · Зевает с zzz

`source.tgs` — неизменённый 089; `zzz-source.tgs` — неизменённый 090.
Крупная синяя голова 069 без глаз; исходная синяя рука прикрывает зевок.
У рта белыми сделаны обе группы: `Group 1` — верхний край, `Group 2` — сама полость.
Времена и контуры рта/руки сохранены.

Три Z взяты из 090 с их исходными путями и движениями. Буквы белые, обводка синяя 2.5 px.
Непрозрачность зависит от фактического раскрытия рта: при закрытом рте букв нет,
при зевке они появляются последовательно. Проверены закрытые кадры 30–95 и полный зевок 150.
