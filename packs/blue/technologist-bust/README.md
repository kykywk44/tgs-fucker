# Technologist · Bust

Проверка: `node packs/blue/technologist-bust/verify.mjs`.

2026-10-22: по просьбе пользователя самолётик Telegram на крышке заменён на ту же
строчную n Roboto Black, что на identification-card. Её точный векторный контур хранится
в `logo.json`. Серый кружок и его краска сохранены; буква вырезана из него, как прежний
самолётик. Ключи буквы получены из исходной формы кружка, поэтому она следует его
положению и сплющиванию при опускании ноутбука.

Остальные фигуры ноутбука, материал, иерархия и исходное движение не меняются.
