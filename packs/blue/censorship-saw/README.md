# Пилит цензуру

Черновик из пользовательского `censpoop.tgs`. Вместо какахи — голова синего
персонажа без шеи, тела и глаз. Пропорции головы, уши, градиент, тёмный контур
и светлый верхний край взяты из общего силуэта пака.

Сохранены исходные повороты, гримасы, зубы, движение кистей/пилы, знак цензуры
и красная стружка. Рот белый, разделители зубов синие. Три альфа-матта головы
скрывают рот за щекой при появлении сбоку, без изменения исходной анимации рта.
Уши сохраняют исходный вид до15кадра, плавно уходят в гладкий боковой контур
к23кадру, затем возвращаются на27–35кадрах. Светлый край макушки следует
тому же контуру; матты рта повторяют его деформацию.
Кисти синие, жёлтая ручка пилы серая. Муха, зелёное зловоние, глаза,
тень какахи и чёрные линии-руки удалены; невидимые родительские слои сохраняют риг.
Просвет у левой кисти закрыт синей перемычкой до основания среднего пальца:
она покадрово следует исходным контурам, включая раскрытие кисти на65–67.
Прежняя полупрозрачная тень
манжеты стала синей непрозрачной подложкой под пальцами, поэтому белый фон
через неё не просвечивает. Серый контур отдельного слоя тени правой кисти
перекрашен в#335375. Обратная сторона держателя пилы тоже серая.

Сборка и проверки:

```powershell
node packs/blue/censorship-saw/build.mjs
node packs/blue/censorship-saw/verify.mjs
.venv/Scripts/python.exe .venv/Scripts/tgs_check.py --level Warning exports/blue/censorship-saw.tgs
node scripts/library.mjs
```

Выход: `exports/blue/censorship-saw.tgs` — 512×512, 60fps, 3с, около23KiB.
Раздел приложения — «Синий пак · черновики». Сравнение с исходником:
`exports/sheets/blue-censorship-saw.png`. Проверяются точные исходные риг/тайминги,
геометрия рта и кистей, отсутствие выхода рта за голову на всех180кадрах,
непустые кадры, формат Telegram и пиксельно точный луп.
