# 573 · Карточка n

Исходная анимация удостоверения сохранена: переворот, появление портрета,
пульсация элементов, анимированный значок глобуса и прорисовка подписи.
В портрете — синяя голова без шеи/глаз с белой улыбкой. Исходные волосы,
глаза, брови, нос, уши и личные данные удалены. Карточка не перекрашивалась.

По уточнению пользователя вместо трёх строк сделана одна большая строчная n
в свободной правой области. Шрифт Roboto Black преобразован в векторные пути,
текстовых слоёв и зависимости от шрифта при проигрывании нет.
Внизу — непрерывный росчерк в форме рукописной n; оригинальные ключи trim-path
сохранены. После появления содержимого улыбка плавно растягивается в 1.65 раза
по ширине и 2.2 по высоте, удерживается и возвращается к исходной перед циклом.
Вся анимация остаётся 3 секунды / 180 кадров.

```powershell
node packs/blue/identification-card/build.mjs
node packs/blue/identification-card/verify.mjs
node scripts/library.mjs
```

Исходник source.tgs — неизменённый library/emoji/573.tgs.
Черновик: exports/blue/identification-card.tgs; JSON редактора: drawing.json.
Все параметры буквы, портрета и улыбки — в recipe.json.
В ready и Telegram до одобрения не добавляется. Предлагаемая ассоциация: 🪪.

Уточнение по композиции: портрет целиком (вместе с улыбкой) поднят на 8 единиц
холста к центру рамки, большая n сдвинута влево на 12. Оба смещения — в recipe.json.
