# 569 · Чёрная бочка · СЕМЯ

Черновик независимого пака, 2026-10-22. Исходная красная эмаль заменена
чёрным графитом с сохранением градиентов, бликов, рёбер и металлической
крышки. Струя, поверхность жидкости внутри и её блики стали белыми.

На гладкой полосе между двумя ободами — белая **СЕМЯ**, Roboto Black.
Кириллица переведена в векторные контуры. Надпись спроецирована на цилиндр:
буквы сжимаются к бокам, верхняя и нижняя границы повторяют дугу поверхности.
Перед проекцией длинные сегменты шрифта делятся; изгибаются и вершины,
и касательные кривых Безье, чтобы избежать изломов букв.

Надпись наследует все движения `TELO` и его родителей. Изменение глубины
дуги и положения печати следует исходным ключам ободов 0/20/30/50.
Крышка и ободы лежат выше печати и естественно перекрывают её.
Исходная анимация, геометрия и прозрачность остальных элементов сохранены.

`source.tgs` — неизменённый оригинал `library/emoji/569.tgs`.
`recipe.json` — параметры; `inscription.svg` — выгнутая надпись в исходной
позе; `FONT-LICENSE.txt` — лицензия шрифта.

```sh
node packs/emoji/barrel/build.mjs
node packs/emoji/barrel/verify.mjs
.venv/Scripts/python.exe .venv/Scripts/tgs_check.py --level Warning exports/emoji/barrel.tgs
node scripts/library.mjs
```
