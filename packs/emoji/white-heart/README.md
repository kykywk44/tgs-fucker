# 🤍 658 · +ąi

Черновик нового пака, 2026-10-22. Белое сердце Telegram из `library/emoji/658.tgs`.
Оригинал хранится в `source.tgs` без изменений.

Надпись **+ąi** — Roboto Black, графитовая `#424247`, ширина 210 px.
Буква `ą` с огонэком взята из latin-ext, остальные знаки — из latin.
`inscription.svg` содержит только контуры, без текста и внешних шрифтов.
Лицензия шрифта — `FONT-LICENSE.txt`.

В TGS две одинаково читаемые надписи на разных сторонах сердца.
Сжатие по горизонтали следует за шириной исходного морфинга сердца;
боковой сдвиг имитирует поверхность объёмного сердца. При виде с ребра
надпись сжимается до невидимой линии, с другой стороны появляется вторая.
Исходные слои и вся анимация сердца сохранены, общий риг пульсации
действует и на надпись. Текстовых слоёв, изображений и expressions нет.

Параметры: `recipe.json`. Сборка и проверка из корня:

```sh
node packs/emoji/white-heart/build.mjs
node packs/emoji/white-heart/verify.mjs
```

Результат: `exports/emoji/white-heart.tgs`, 512×512, 60 fps, 3 с.
