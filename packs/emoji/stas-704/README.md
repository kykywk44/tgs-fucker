# 704 · СТАС

Белый символ младенца заменён векторной надписью **СТАС**, Roboto Black,
ширина 350 px. Чёрная рельефная тень также заменена контурами букв.
Исходные родительские трансформации, сжатие при повороте, видимость,
подгузники, вонь и блеск сохранены. Исходник `source.tgs` не изменяется.

Сборка: `node packs/emoji/stas-704/build.mjs`.
Проверка: `node packs/emoji/stas-704/verify.mjs`.
Результат: `exports/emoji/stas-704.tgs`; в приложении «Черновики» → `stas-704`.
Отдельная надпись — `inscription.svg`, лицензия — `FONT-LICENSE.txt`.
