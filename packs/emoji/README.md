# Новый пак эмодзи

Отдельный пак для совместной работы над эмодзи. Создан 2026-10-22.
Название, стиль и состав пока не выбраны; `emoji` — рабочее имя папки.

## Структура

- `<имя>/` — рабочая папка отдельного эмодзи: исходник `source.tgs`, рецепт
  `recipe.json` и, при необходимости, собственный `build.mjs`.
- `ready/` — только готовые `.tgs`, одобренные пользователем.
- Результаты сборок и превью — в `exports/emoji/` и
  `exports/sheets/emoji-<имя>.png` соответственно.

Исходники сохраняем без изменений. Для эмодзи из `library/emoji/` записываем
номер исходника в рецепте или README соответствующего эмодзи.

## Независимость от Blue

Работа ведётся внутри `packs/emoji/`; файлы, рецепты, стиль и готовые эмодзи
из `packs/blue/` не изменяем. Стиль нового пака определим отдельно.

## В работе

- [`white-heart/`](white-heart/README.md) — белое сердце 658 с векторной
  надписью `+ąi` с обеих сторон, черновик.
- [`diaries/`](diaries/README.md) — книги 637: графитовые дневники с мягкими
  углами и белым `+ąi` на верхней обложке, черновик.
- [`calendar/`](calendar/README.md) — календарь 631: на всех страницах `+AI`
  вместо чисел, месяцы меняются, сердечки убраны, черновик.
- [`barrel/`](barrel/README.md) — бочка 569: чёрный металл, белая жидкость
  и белая надпись «СЕМЯ» по изгибу цилиндра, черновик.
- [`photo-devices/`](photo-devices/README.md) — фото в телефоне 554, ноутбуке 556,
  принтере 558 и картине 606; выбор фотографии и отправка отдельным стикером
  в бота доступны в видеопредпросмотре этих четырёх черновиков.

Все новые эмодзи показываем в основном приложении `http://localhost:5173/`:
вкладка «Эмодзи» → «Черновики». Она читает `exports/emoji/*.tgs`.
После каждой новой сборки обновляем индекс: `node scripts/library.mjs`.
Разделы «Синий пак · готово» и «Синий пак · черновики» остаются отдельными.

Пользователь сам открывает черновики и управляет редактором. После сборки
не переключаем вкладки, не открываем файл и не двигаем кадры за него;
проверяем анимацию офлайн через tlottie и таблицы кадров.
