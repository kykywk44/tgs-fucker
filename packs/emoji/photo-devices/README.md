# Настраиваемые фотостикеры

255 (`egg-photo-255`) и 222 (`hat-photo-222`) используют вырезанный портрет
из игнорируемого `private/staspng.png`. У яйца удалены фигуры цыплёнка;
портрет наследует поворот головы, движение тела и обе фазы исходного цикла.
Передняя скорлупа перекрывает фото. В шляпе удалены уши, портрет появляется
и опускается в прежнем интервале, обрезается по родной анимированной кривой
переднего края отверстия. `popups.mjs` готовит проекции и планы сцены.
Оба доступны в общих «Черновиках» с заменой фото и отправкой через бота.

`private/photo.png` — локальный оригинал фотографии пользователя. Папка
игнорируется Git и не выдаётся Vite по HTTP, включая `/@fs/` и кодированные
пути. Оригинал не отслеживался Git. Исходные `source-*.tgs` не изменяются.

Ноутбук: содержимое включённого экрана заменено фото на всю площадь.
Проекция наследует трансформации экрана, его прозрачность и момент выключения.
Оригинальный блик накладывается поверх фотографии.

Принтер: логотип на выходящем листе убран. Фото следует углам листа,
обрезается его анимированным контуром и перекрывается передней частью принтера.
Входящий лист остаётся пустым; фотография появляется только при выходе бумаги.
На отпечатке сохранены поля. Проекция четырёхугольная, мелкие изгибы краёв
сохраняются в обрезке исходным контуром бумаги.

Телефон: фото заменяет значки приложений, сохраняется поворот и передняя камера.
На кадрах 78–100 фото уменьшается с крупного фрагмента до полной площади экрана.
Скругления экрана остаются маской.

Картина: пейзаж заменён проявлением по накопленному следу кисти в координатах
холста. К кадру 152 фото раскрывается полностью, на 154–178 растворяется.
Начало и конец показывают пустой холст. Рама и кисть сохраняют движение.

573: вместо головы в фоторамке удостоверения — выбранная картинка.
621: фото заменяет печатные строки на обеих версиях листа; передние части
конверта и сердечко перекрывают его согласно исходному порядку слоёв.
632: изображение на всех бюллетенях следует кривым Безье четырёх краёв бумаги
через сетку Coons, включая загибы и перевороты. Карта видимости каждой бумаги
учитывает коробку и остальные листы; скрытые поверхности не рендерятся повторно.
950: универсальный флаг с плавной периодической волной. Фото деформируется
сеткой 24×12 без самопересечений и скачков исходных складок; освещение следует
волне, начало и конец движения совпадают.

569 и 704: при открытии бочки и подгузника в «Черновиках» доступен свой текст
(до 32 символов, заглавными). Буквы переводятся в векторные контуры; бочка
сохраняет цилиндрическую проекцию, подгузник — исходный поворот и тень.
Кнопки позволяют применить текст, скачать TGS или отправить отдельным стикером
в бота. Индивидуальные сборки не перезаписывают общие варианты.

Сборка: `node packs/emoji/photo-devices/build.mjs`.
TLottie рендерит исходную сцену, передний план, маску поверхности и цветовые
маркеры углов. Pillow проецирует фото; ffmpeg кодирует VP9 с альфа-каналом.
Все ролики — 512×512, 30 fps, 90 кадров / 3 секунды, без звука, до 256 KiB.
Длительность WebM не подменяется.

Результаты: `exports/photo-devices/*.webm`, копии в `exports/emoji/` для
основных «Черновиков». Таблицы кадров и PNG рядом с роликами.
В видеопредпросмотре каждого из восьми шаблонов можно выбрать PNG/JPEG/WebP,
нажать «Применить фото» или «Создать и отправить в бота». Готовый вариант
отправляется отдельным стикером, без добавления в наборы. Скачивание сохранено.

`server/photo-stickers.ts` обслуживает приватную очередь заданий под общей
авторизацией сайта. Пользовательские фото принимаются только по POST с проверкой
источника и размера; Python проверяет формат и число пикселей, учитывает EXIF
ориентацию. Загрузки и результаты живут в игнорируемой `exports/photo-custom/`;
прямая статическая выдача каталога запрещена. Оригинал загрузки удаляется после
обработки, клиент получает только готовый WebM через API по случайному ID задания.
Один и тот же результат не отправляется повторно при повторном нажатии.

`send.py --job <папка задания>` отправляет готовый вариант владельцу настроенного
бота отдельным видеостикером по нажатию пользователя. Не добавляет его в наборы,
не читает обновления и не меняет состояние работающего бота.
