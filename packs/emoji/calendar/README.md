# 📅 631 · Календарь · +AI

Черновик, 2026-10-22. На всех страницах вместо чисел одна и та же надпись
**+AI**. Названия месяцев сверху, красная шапка, точки, кольца, бумага и
исходное перелистывание сохранены.

Десять групп дат (две страницы JUL, AUG, SEP, OCT, DEC, FEB, APR, MAY, JUN)
заменены векторными контурами Roboto Black. Ширина надписи 240 px,
цвет `#414141`; буквы не зависят от шрифта в системе. Исходные трансформации,
сжатие листов и видимость печати при переворотах сохранены. Группа каждого
месяца и все остальные элементы вне дат не изменены.

Каждая надпись вынесена в отдельный дочерний слой и обрезается альфа-маской
своего листа. Маска повторяет исходный анимированный контур лицевой стороны
бумаги: при перелистывании старая печать не выступает за сгиб и не остаётся
на следующей странице. Проверка всех 179 кадров контролирует эту границу
для каждой из десяти страниц, включая участки вокруг кадров 11, 33, 56, 76,
100, 118, 126, 137 и 143.

Слой `Heart` (39) с рисунками-сердечками на странице 14 FEB удалён.
В оригинальной надписи FEB убран неподдерживаемый Merge Paths режима 1:
рендер с ним и без него совпадает во всех 179 кадрах.
Оригинал `source.tgs` сохраняется без изменений.

Параметры и точный список групп — `recipe.json`.
`inscription.svg` — отдельная векторная надпись; лицензия — `FONT-LICENSE.txt`.

```sh
node packs/emoji/calendar/build.mjs
node packs/emoji/calendar/verify.mjs
node scripts/library.mjs
```
