# Видео из графики синего пака

Отдельная сцена с лифтом: `trailers/blue-elevator/README.md`. Четыре копии
пользовательского SVG, перекраска в палитру пака, плавный риг корпуса/головы/рук,
общие толчки кабины и периодический пружинный отклик. Сборка:
`node trailers/blue-elevator/assets.mjs`, затем
`python trailers/blue-elevator/render.py`. Выход `exports/blue-elevator/`,
10 секунд / 4:3, мастер 1440×1080×60 и лёгкий MP4 960×720×30.

Одобренная сцена и воспроизводимая сборка: `trailers/blue-crowd/`.
Это видео, а не TGS: длительность и разрешение не ограничены правилами стикеров.
Графика остаётся векторной в исходниках, кадры рендерит установленный tlottie.

## Полная сборка из корня репозитория

```powershell
powershell -ExecutionPolicy Bypass -File trailers/blue-crowd/build.ps1
```

Только лёгкий экспорт из уже готового мастера:

```powershell
powershell -ExecutionPolicy Bypass -File trailers/blue-crowd/build.ps1 -TelegramOnly
```

Node использует зависимости проекта. Нужен Python с Pillow (системный `python`;
в проектной `.venv` Pillow отсутствует). FFmpeg/ffprobe берутся из PATH или
`C:/Program Files/FFmpeg 8/`. Новые библиотеки не устанавливаются.

## Порядок работы

1. `scene.json` задаёт композицию, шесть рядов, период мира, камеру и времена героя.
2. `assets.mjs` замораживает нужные позы одобренных TGS, переносит исходные кривые
   смеха и зубы из 070, рендерит отдельные проходы тела и ноутбука в PNG 768×768.
   Исходники: ready/technologist-bust, middle-finger, face-with-hand-over-mouth.
3. `render.py --preview` собирает раскадровку и проверяет стыки без кодирования.
   Без флага — 12 с / 1920×1080 / 60 fps, H.264 BT.709, без звука.
4. `telegram.py` делает MP4 1280×720 / 30 fps / H.264 High CABAC / yuv420p,
   1400 kbit/s, GOP 60, faststart. Результат около 2.1 MB вместо 22.9 MB.
   Другой мастер/путь: `python trailers/blue-crowd/telegram.py --input master.mp4 --output small.mp4`.
5. Проверить storyboard, крупный план героя, движение в MP4; ffprobe и полное
   декодирование, все кадры и длительность. `telegram.py` делает технические проверки сам.

## Важные решения и ошибки, которые не надо повторять

- В каждом ряду сначала рисовать **все тела**, затем **все ноутбуки**. Иначе плечо
  следующего человека перекрывает соседнюю крышку. Между рядами порядок глубины сохранять.
- Пять дальних рядов непрозрачны. Над ними один экранный белый→прозрачный градиент;
  первый ряд рисуется после градиента. Прозрачность каждого человека выглядит иначе.
- Печатание — безопасные первые 0–50 кадров Bust, крышка фиксирована открытой,
  исходные руки для закрывания скрыты. Разные целые числа циклов/фазы за весь ролик.
- Переход героя начинается с **точной входной позы**, затем затухает в неподвижную.
  Не переключать весь исходник на другое время: скачут голова, крышка и руки.
- Крышка морфится отдельно. Кисть привязана к её углу, подходит по дуге из-за панели.
  Подъём с наружного края выдавал внезапное появление запястья.
- Жест отзеркален на анатомическую левую руку, спокойная поза кадра 0. Не играть
  исходный тычок и трясущийся кулак. Масштаб 48%, обводка после масштаба 7.44 px,
  низ кисти скрыт крышкой. После старта камеры покачивания усиливаются до ±8°.
- Рот и небольшая тряска головы взяты из 070 (20–115), исходные Bezier-кривые
  сохранены. Рот 60% от исходника, высота не ниже 65%; без фейда/тонкой щели.
- Камера трогается, пока герой держит жест; затем он успокаивается, убирает руку,
  открывает крышку и **не печатает** до выхода из кадра.
- Камера — интеграл плавных кривых скорости, общий путь кратен шагу рядов.
  Мир повторяется через 8 колонок. Кадры t=0/t=12 должны совпадать побайтно,
  скорости камеры на стыке тоже; активный герой к этому времени вне кадра.
- OpenH264 установлен; libx264 здесь отсутствует. Мастер/лёгкий файл сохранять
  отдельно, новым правкам давать новое имя, чтобы просмотр не показывал старый MP4.

Детальные тайминги: `trailers/blue-crowd/README.md`, `scene.json`.

## Видео для анонса паков

Одобренные crowd v3 и elevator v6 отдельно сохранены в `exports/post-videos/01-blue-crowd/`
и `02-blue-elevator/`, мастер и лёгкая версия. SHA-256 и метаданные в manifest.json.
Локальная галерея `exports/post-videos/index.html` содержит также новый черновик
широкой ленты `03-emoji-strip/`. Пайплайн ленты — `trailers/blue-carousel/README.md`.
N-bubble появляется маленьким с поворотом по часовой, выпрямляется, эмодзи
переключаются с ускорением и замедлением, N-флаг проигрывается один раз и исчезает.
Skibidi в ленте исключён; TGS для него лежит в синих черновиках отдельно.
