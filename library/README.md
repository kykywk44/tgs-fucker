# Библиотека эмодзи

## Подарки Telegram

На новом устройстве (из корня проекта, после `npm install`):

```bash
node scripts/download-gifts.mjs   # ~277 MB, 7 956 TGS; оборвалось — запустить снова, продолжит
node scripts/library.mjs          # превью и индекс вкладки
```

`node scripts/download-gifts.mjs` скачивает все `.tgs` из каждой папки
`https://cdn.changes.tg/gifts/models/`. Список подарков дополнительно проверяется
через `https://api.changes.tg/gifts`; статистика API хранится в каталоге.
Источник данных — GiftChanges. В приложении есть ссылка на источник.

Локально: `library/gifts/models/<подарок>/<модель>.tgs`. На 24.10.2026 скачано
7956 TGS из 123 папок (включая Original и дополнительные модели в папках).
Исходные имена хранятся в `library/gifts/catalog.json`, Windows-запрещённые
символы файлов кодируются без потери имени (например, `AC\DC` → `AC%5CDC`).
Файлы не коммитятся. Импорт повторяемый: валидный gzip/Lottie используется из
кэша, повреждённые файлы скачиваются заново, временные файлы переименовываются
только после проверки. Четыре параллельных загрузчика, паузы, повторы сетевых
ошибок/5xx и общий учёт 429/Retry-After. Полный отчёт — download-report.json;
старый полный каталог сохраняется до успешного завершения следующего импорта.

Затем `node scripts/library.mjs` строит локальные превью и вкладку «Подарки».
Сначала крупные карточки основных подарков (Original), по нажатию — варианты.
Поиск работает по названию подарка/модели, ID и рецепту, фильтры есть во всех
разделах библиотеки. Двойной клик открывает модель в редакторе; «Скопировать ID»
даёт устойчивое имя `Подарок/Модель`, а не номер, зависящий от сортировки.
В рецепте можно указать `"gifts": ["Scared Cat/Salem"]`, чтобы модель получила
пометку «есть синяя версия». Превью кэшируются по подарку и состоянию файлов:
пересборка синего пака не рендерит повторно все тысячи подарков.

## Обычные эмодзи

`emoji/001.tgs … 997.tgs` — анимированные эмодзи Telegram в порядке набора (архив `RestrictedEmoji_tgs.zip`
от пользователя, 2026-10-21; 36 MB). Номер файла — его ID во вкладке «Эмодзи» редактора. Имена внутри
файлов (`nm`) ненадёжные («Comp 1»), поэтому ищем по картинкам.

В git не хранится (`.gitignore`): чужие файлы и 36 MB. Восстановить:

    unzip RestrictedEmoji_tgs.zip -d library/emoji
    node scripts/library.mjs     # library/index.json + library/thumbs/*.png для вкладки «Эмодзи»

`scripts/library.mjs` надо перезапускать после новых синих эмодзи: наборы вкладки — «Эмодзи Telegram», «Синий пак · готово»
(`packs/blue/ready/`) и «Синий пак · черновики» (`exports/blue/`, выход `restyle.mjs`; ID — имя файла). Синяя точка
в общей сетке — у эмодзи, для которых есть рецепт.
